**GTA VI Trophy Guide & Tracker** — an offline guide to all 55 PlayStation 5 trophies of Grand Theft Auto VI, with a cited guide for every trophy, a six-stage roadmap to the Platinum, and the one missable trophy flagged everywhere it matters. The tracker saves your progress in the browser, exports and imports it as a file, filters by kind, grade and text, and keeps story trophies behind a spoiler shield until you earn them. Every specific method in a guide names its source beside it. Static files, no build step, no network at run time.

## Run it

```sh
node serve.ts
# then open http://localhost:8000 — or serve app/ with any static file server
```
